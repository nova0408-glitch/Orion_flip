# Orion Flip

A beautiful, realistic digital flip clock with animated flipping digits and rotating inspirational quotes. Built with pure HTML, CSS, and JavaScript — no dependencies required.


## ✨ Features

- **Realistic Flip Animation**: Smooth 3D flipping digits for hours, minutes, and seconds
- **Live Time Update**: Updates every second with accurate system time
- **Random Inspirational Quotes**: Automatically cycles through motivational quotes every 12 seconds
- **Responsive Design**: Works great on desktop and mobile devices
- **Modern Dark Theme**: Clean, elegant UI with subtle shadows and realistic card styling
- **Zero Dependencies**: Vanilla HTML/CSS/JS — just open `index.html`

## 🚀 How to Use

1. Download or clone this repository
2. Open `index.html` in any modern web browser
3. The clock will start automatically and show the current time
4. Quotes will change every 12 seconds
